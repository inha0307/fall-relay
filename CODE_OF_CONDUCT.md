# Code of conduct

Fall-Relay follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive in issues, pull requests and any other project space; criticise code and
claims, not people; do not harass, insult or publish anyone's private information.

The project's camera data rules are part of this code: never post event databases, clips, camera images or other
recordings of a person in an issue or pull request (see [CONTRIBUTING.md](CONTRIBUTING.md)).

To report unacceptable behaviour, e-mail the maintainers at emforhs033@kangwon.ac.kr. Reports are read by the
maintainers only and handled confidentially; the maintainers may remove content or block participants who break
this code.
